# 5-8分钟演示脚本

作者：非增程式柠檬

## 1. 正常态势（约1分钟）

打开平台，说明左侧是统一网格化的海域通信需求，船舶颜色对应运动状态和通信业务画像。拖动时间轴，说明系统每5分钟更新一次。

## 2. 捕捞热度上升（约1分钟）

切换“捕捞热度上升”，拖动到12:30-15:50区间。指出低速重复转向船舶增多，相关网格流量与热度同步上升，点击网格查看证据。

## 3. 直播上行激增（约1分钟）

切换“直播上行激增”，说明仅看总流量容易漏掉上行压力，而上下行结构可以帮助运营商识别直播/监控回传，页面会给出上行资源保障建议。

## 4. 船舶群聚与容量保障（约1分钟）

切换“船舶群聚”，观察局部网格颜色变暖、船舶轨迹集中和负载上升。点击告警记录，展示“流量证据 + 船舶证据”的联合解释。

## 5. 通信中断与交叉核验（约1分钟）

切换“通信中断”，说明即使流量骤降，轨迹仍然存在，系统可以把网络侧异常和船舶侧证据放在一起，减少单一数据源带来的误报。

## 6. 投资价值收束（约1分钟）

强调平台不是单纯的可视化，而是把海上通信数据转化为可执行的容量保障、重点巡检和行业服务建议；后续可对接企业授权的聚合数据，形成区域化运营产品。
