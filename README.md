# 基于5G流量与轨迹融合的海域作业智能感知及预警平台

作者：非增程式柠檬
版本：V0.4
定位：面向命题企业的海域通信智能感知与网络保障试点交付包

这是面向海上通信运营、政企客户服务、海洋治理协同和行业数据产品化的可运行试用项目。当前版本已形成“仿真数据 → 5G流量与船舶轨迹时空融合 → 海域热度 → 作业画像 → 联合预警 → 网络资源建议 → 交互导出”的企业验证闭环。

## 目录

- `prototype/`：可直接启动的本地交互网站、仿真器、分析引擎、样例数据与验证报告。
- `source/`：可继续编辑的项目计划书源文件。
- `release/`：面向提交的只读计划书、发布说明和SHA-256清单。
- `docs/`：计划书摘要。
- `tools/`：完整性校验工具。

## 快速试用

1. 进入 `prototype/`。
2. 执行 `powershell -ExecutionPolicy Bypass -File .\scripts\run_demo.ps1`。
3. 浏览器打开 `http://127.0.0.1:8765/`。
4. 切换场景、拖动时间轴、点击网格/船舶/告警，最后导出当前状态。

## 已交付能力

- 12×12海域网格、5分钟时间窗、24小时确定性仿真。
- 正常基线、捕捞热度上升、船舶群聚、通信中断、直播上行激增五类场景。
- 热度四级识别、运动状态与通信业务分层画像、联合异常预警。
- 本地健康检查、状态查询和JSON导出接口。
- 样例数据、演示脚本、验证报告和企业试点阶段计划。
