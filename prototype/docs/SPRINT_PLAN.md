# 企业试点阶段实施计划

作者：非增程式柠檬  
目标：形成可运行、可演示、可解释、可验收的企业试点验证包，并为授权数据接入和区域化复制预留接口。

## 阶段安排

| 阶段 | 工作包 | 交付结果 |
|---|---|---|
| 准备 | 冻结范围与目录 | P0清单、配置、作者与许可证边界 |
| 数据 | 确定性仿真 | 五类场景、AIS/北斗轨迹、5G流量、事件真值 |
| 分析 | 融合与识别 | 网格-时间窗对齐、热度、作业画像、异常规则 |
| 服务 | 接口与导出 | 健康检查、状态查询、当前状态导出 |
| 演示 | 交互平台 | 热力图、轨迹、时间轴、告警、证据、资源建议 |
| 验证 | 指标与边界 | 热度准确率、行为识别、异常召回率和限制说明 |
| 发布 | 文档与验收 | 计划书、样例数据、演示脚本、完整性清单、压缩包 |

## 首期验证范围

- 12×12海域网格、5分钟时间窗、24小时仿真数据；
- 正常基线、捕捞热度上升、船舶群聚、通信中断、直播上行激增；
- 流量与轨迹统一到 `grid_id + time_window`；
- 高/中/低/非热点四级识别；
- 船舶运动状态与通信业务行为分层识别；
- 流量突增、流量骤降、群聚、上行激增联合预警；
- 浏览器交互、场景切换、时间播放、点击联动、状态导出；
- 指标报告与可解释证据卡片。

## 首期边界

- 真实运营商原始流量接入；
- 5G NR物理层或核心网仿真；
- 复杂GIS底图、云数据库、账号权限和生产部署；
- 重型深度学习训练与在线大模型调用；
- 将仿真指标包装成生产网络承诺。

## 企业验收门槛

1. 执行启动脚本后能打开本地网站；
2. 场景切换和时间轴拖动能够更新热力、轨迹、趋势和告警；
3. 试用版接口响应包含144个网格和80艘船舶；
4. 仿真验证中热度准确率不低于85%；
5. 有事件的场景异常召回率不低于85%；
6. 目录中不含真实敏感数据；
7. 提交包含作者声明、第三方说明、版本号和SHA-256清单。
