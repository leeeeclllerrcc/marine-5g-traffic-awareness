# 海域智能感知与预警平台（试用版）

作者：非增程式柠檬  
版本：V0.4  
定位：面向海上通信运营、海洋治理和渔业安全场景的企业试点演示平台，支持从合成数据验证平滑过渡到授权聚合数据接入。

## 一键运行

在本目录下执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_demo.ps1
```

然后打开 `http://127.0.0.1:8765/`。

也可以直接执行：

```powershell
python .\src\server.py
```

本项目不依赖外部地图服务、数据库或在线模型，首次试用即可运行。所有样例均为合成数据，不含运营商真实数据或个人信息。阶段化实施计划见 `docs/SPRINT_PLAN.md`。

## 试用功能

- 5分钟时间窗播放和时间轴拖动；
- 12×12仿真海域网格热度分级；
- 船舶轨迹、运动状态和通信业务画像；
- 流量突增、流量骤降、船舶群聚、轨迹中断等预警；
- 场景注入：捕捞热度上升、船舶群聚、通信中断、直播上行激增；
- 网络资源建议：重点保障、上行资源扩容、容量巡检；
- 前端选择联动、告警详情和趋势曲线；
- `/api/state` 可输出当前时刻完整结构化状态。

## 核心设计

系统将5G业务流量与船舶轨迹统一到“网格ID + 5分钟时间窗”，分别识别：

1. 海域热度：高热度、中热度、低热度、非热点；
2. 船舶状态：航行、锚泊、疑似捕捞、低速漂移；
3. 通信行为：普通数据、视频下行、直播/监控上行；
4. 风险事件：流量突增、流量骤降、群聚、轨迹中断。
