# 数据字典（试用版）

作者：非增程式柠檬

## 船舶轨迹字段

| 字段 | 含义 | 单位/示例 |
|---|---|---|
| `timestamp` | 时间窗起点 | ISO时间 |
| `vessel_id` | 仿真船舶标识 | V-001 |
| `lon` / `lat` | 经度/纬度 | 演示坐标 |
| `grid_id` | 海域网格 | G01-01 |
| `sog` | 对地航速 | kn |
| `cog` | 对地航向 | degree |
| `turn_rate` | 转向强度 | 0-1 |
| `truth_behavior` | 仿真真值标签 | 航行/锚泊/疑似捕捞/直播 |

## 5G流量字段

| 字段 | 含义 | 单位/示例 |
|---|---|---|
| `up_bytes` | 上行字节数 | bytes/5分钟 |
| `down_bytes` | 下行字节数 | bytes/5分钟 |
| `active_devices` | 活跃终端数 | count |
| `prb_load` | 资源块负载估计 | % |
| `signal_dbm` | 信号强度 | dBm |
| `event_truth` | 仿真事件标签 | 仅用于离线评价 |

## 隐私处理

试用版不包含手机号、IMSI、IMEI、真实船名、个人位置或运营商原始日志。正式接入时只保留聚合到网格和时间窗后的统计信息，并对标识符做不可逆脱敏或一次性映射。
